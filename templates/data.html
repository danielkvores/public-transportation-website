Data Explorer

All charts pull live from the database. Each point, band, or range is built from NUTS-2 regions. Start with a country, then zoom out to the wider divide.

01

Start With a Country

Select a country to see every region against its national average and the EU-27 average. This keeps the comparison personal without pretending that every country has the same internal geography or the same data coverage.

Select a country to load its regional data

Dots show NUTS-2 regions. The red reference line is the selected country average; the dark dashed line is the EU-27 average. Dot colours keep the urban/intermediate/rural typology. Missing metrics are hidden instead of being treated as zero.

02

The Divide Is Not the Same Europe

The old EU-wide average hid the main nuance. Here, countries are split into lower- and higher-GDP halves first, then regions are grouped by urban-rural typology. The rural-urban gap is visibly sharper in the lower-GDP half.

Source: Eurostat nama_10r_2gdp (GDP per capita, PPS), tran_r_net (railway density), lfst_r_lfe2emprt (employment), demo_r_mlifexp (life expectancy), edat_lfse_04 / edat_lfse_16 (education). Country split is based on average regional GDP per capita.

03

Rail Density Without the Point Cloud

Instead of a scatter plot where rural regions collapse into one cluster and urban regions explode across the canvas, regions are grouped into four railway-density bands. The pattern is easier to read, and the limits of the proxy stay visible.

Source: Eurostat tran_r_net (2024) and selected outcome datasets. Only regions with railway-density data are included in the bands.

04

Where Countries Split Apart

The old top-and-bottom list blurred together dozens of regions. This view ranks countries by the gap between their strongest and weakest NUTS-2 regions for the selected indicator.

Each horizontal range runs from the lowest to highest NUTS-2 region in a country. The pale dot marks the lowest region; the red dot marks the highest. Countries with fewer than two available regional values for the selected metric are excluded from that view.
