About this project

Stage II of a data engineering assignment — University of Amsterdam, 2026.

The argument

Where the Lines End argues that public transport is the great equaliser across the EU — or, more precisely, that its absence is the great divider. Regions that sit further from urban centres and major transport corridors systematically underperform on employment, health, and educational attainment.

The thesis is not that rural life is inherently worse, but that structural under-investment in connectivity has created a compounding disadvantage for peripheral regions. A region without good public transport cannot attract firms, retain young graduates, or ensure that residents can reach hospitals and job centres efficiently.

Design decisions

The site is intentionally structured as a data journalism piece rather than an academic report. The landing page makes the argument in plain language; the data page proves it with charts; the methodology page explains how the evidence was gathered and what its limits are.

Visualisations use Chart.js (CDN, no build step), fed by JSON API endpoints from the Flask backend. All data is queried live from the SQLite database — nothing is hardcoded into HTML.

The colour palette uses blue for urban regions, teal for intermediate, and amber for rural — consistent across all charts so the reader builds an intuitive association between colour and classification.

Technical stack

  • Backend: Python 3.13, Flask 3.x, SQLite3 (raw, no ORM)
  • Data pipeline: pandas 3.x for cleaning; parameterised executemany for insertion
  • Frontend: Vanilla HTML/CSS, Chart.js 4.x (CDN), no JavaScript frameworks
  • Data: Eurostat SDMX-CSV 2.0 (8 datasets, gzipped)
  • Database: SQLite, 7 tables, foreign-key constraints

Scope

This is a student assignment (Stage II of three). The data covers all 27 EU member states at NUTS-2 regional level. Candidate countries (e.g. Serbia, Ukraine) and UK post-Brexit data are excluded. Greece uses the Eurostat country prefix "EL", not "GR".
