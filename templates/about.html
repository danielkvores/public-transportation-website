About this project

Stage II of a data engineering assignment — University of Amsterdam, 2026.

The argument

Where the Lines End examines whether regional connectivity helps explain why opportunity is distributed unevenly across the EU. It compares transport infrastructure with employment, education, health, and income indicators at NUTS-2 level, then asks where national averages hide large internal differences.

The thesis is not that rural life is inherently worse, or that railway density alone explains regional inequality. The narrower claim is that peripheral regions with thinner fixed transport infrastructure can face a practical access disadvantage: jobs, universities, hospitals, and public services may exist in the country, but not within easy reach.

Design decisions

The site is intentionally structured as a data journalism piece rather than an academic report. The landing page makes the argument in plain language; the data page tests it with charts; the methodology page explains how the evidence was gathered and what its limits are.

Visualisations use Chart.js (CDN, no build step), fed by JSON API endpoints from the Flask backend. All data is queried live from the SQLite database — nothing is hardcoded into HTML.

The colour palette uses blue for urban regions, teal for intermediate, and amber for rural — consistent across all charts so the reader builds an intuitive association between colour and classification.

Technical stack

  • Backend: Python 3.13, Flask 3.x, SQLite3 (raw, no ORM)
  • Data pipeline: pandas 3.x for cleaning; parameterised executemany for insertion
  • Frontend: Vanilla HTML/CSS, Chart.js 4.x (CDN), no JavaScript frameworks
  • Data: Eurostat SDMX-CSV 2.0 (9 gzipped datasets) plus the NUTS 2021 urban-rural typology spreadsheet
  • Database: SQLite, 8 core analytical tables, foreign-key constraints

Scope

This is a student assignment (Stage II of three). The analytical database covers all 27 EU member states and retains 242 NUTS-2 regions after joining the indicator files to the NUTS 2021 urban-rural typology. Candidate countries and non-member countries are excluded. Greece uses the Eurostat country prefix "EL", not "GR".
